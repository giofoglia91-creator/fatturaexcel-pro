Domande Frequenti

I miei file XML vengono caricati su un server?

No, mai. FatturaExcel Pro elabora i file XML e P7M interamente sul tuo dispositivo tramite JavaScript. Puoi persino staccare la connessione Internet dopo aver aperto la pagina e la conversione continuerà a funzionare.

Supporta anche gli XML dei Corrispettivi Giornalieri RT?

Sì. Riconosce automaticamente i file XML DatiCorrispettivi (COR10) estratti dai Registratori Telematici o dal portale Fatture e Corrispettivi, estraendo progressivo, matricola RT, imponibili suddivisi per aliquota IVA, ventilazione, contanti, elettronico e ticket.

Come vengono gestite le Note di Credito (TD04)?

Il parser riconosce automaticamente <TipoDocumento>TD04</TipoDocumento> (e TD08) e applica il segno negativo (-) a Imponibile, IVA e Totale Documento, così la somma della colonna Excel restituisce il saldo contabile esatto.
